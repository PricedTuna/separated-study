# 🧠 Knowledge System (Markdown-First Editor)

A minimal, fast, and structured knowledge management system built with **React**, **Vite**, and **Milkdown**.

---

## 📌 What is this?

This project is a **knowledge management system** designed to create, edit, and organize content using **Markdown as the single source of truth**.

It provides a clean and distraction-free writing experience (similar to Notion or Hashnode), but with a key difference:

> **All content is stored as raw Markdown, not proprietary formats.**

---

## 🎯 Purpose

This system is built to:

- Write and manage notes, documents, and knowledge in a structured way
- Maintain full control over your data (no lock-in)
- Provide a simple and fast editing experience
- Enable easy storage, retrieval, and rendering of Markdown content
- Serve as a foundation for more advanced features (search, tagging, relationships)

---

## ⚙️ Tech Stack

- **Frontend**
  - React
  - Vite
  - Milkdown (Markdown editor)
  
- **Editor**
  - Milkdown (ProseMirror-based)
  - Markdown parsing and serialization

- **Storage**
  - Database (stores raw Markdown as string)
  - Optional local-first support
